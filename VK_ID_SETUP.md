# Подключение VK ID

**Устарело:** VK ID больше не используется для входа в приложение. Актуальная настройка регистрации и входа по email описана в [API_SETUP.md](API_SETUP.md), а контракт — в [BACKEND_API.md](BACKEND_API.md). Инструкции ниже сохранены только как история прежней интеграции.

Стартовый экран и вызов официального [VK ID SDK для iOS](https://github.com/VKCOM/vkid-ios-sdk) уже добавлены. Пока параметры приложения не заданы, кнопка входа показывает сообщение о настройке. Деморежим открывает приложение без VK ID.

Для рабочего входа создайте приложение VK ID для iOS с bundle ID `maxproger.quadrofriends`, затем:

1. Скопируйте `Local.xcconfig.example` в `Local.xcconfig` в корне iOS-проекта. Заполните `VK_CLIENT_ID` (ID приложения из кабинета VK ID) и `VK_CLIENT_SECRET` (защищённый ключ). Локальный файл игнорируется Git; оба значения подставляются в `Info.plist` при сборке Debug и Release. Bundle ID в кабинете должен быть `maxproger.quadrofriends`.
2. На локальном backend задайте тот же `VK_CLIENT_ID` в его `.env` или окружении и перезапустите сервер. Для входа backend должен отвечать на `http://localhost:8080/external/health`.
3. В поле Universal link в кабинете VK ID укажите `https://api.pdfshare.ru/vk_id_redirect`.
4. В Xcode выберите команду Apple Developer для подписи приложения. В проекте уже подключён `quadrofriends.entitlements` с `applinks:api.pdfshare.ru` для Debug и Release.
5. Узнайте Apple Developer Team ID (10 символов), замените `APPLE_TEAM_ID` в `deployment/apple-app-site-association.template.json` и опубликуйте результат **без расширения** по адресу `https://api.pdfshare.ru/.well-known/apple-app-site-association`. Сервер должен отдавать JSON по HTTPS без редиректа. Bundle ID в файле — `maxproger.quadrofriends`.
6. Проверьте вход и возврат из приложения VK на устройстве. Успешная авторизация сохраняется в сессии SDK; пункт меню профиля выполняет выход.

Если при запуске сразу открываются демонстрационные данные, в профиле нажмите `⋯` → «Вернуться к экрану входа», затем «Войти через VK». Выбор «Деморежим» сохраняется между запусками приложения. После входа через VK серверные данные сейчас подключены в чатах, сообщениях и геолокации чата; маршруты, карта и часть профиля пока показывают `MockData`.

### Проверка на устройстве

1. Убедитесь, что `curl -i https://api.pdfshare.ru/.well-known/apple-app-site-association` возвращает `200`, JSON с вашим Team ID и без перенаправления. Файл должен быть доступен именно на поддомене `api.pdfshare.ru`.
2. Установите заново сборку приложения на iPhone после публикации файла. Отправьте себе `https://api.pdfshare.ru/vk_id_redirect` в Заметки или Сообщения и нажмите ссылку. Она должна открыть приложение. Ввод адреса в строку Safari не является проверкой Universal Link.
3. Нажмите «Войти через VK» в приложении и пройдите авторизацию. Приложение должно открыться снова; после получения токена оно обратится к backend `POST /sessions`. Для полного входа backend должен быть доступен.

Симулятором можно быстро проверить существующую URL-схему командой `xcrun simctl openurl booted 'vk<APP_ID>://test'` (замените `<APP_ID>` на VK ID приложения). Это проверяет лишь открытие приложения, а не завершение входа. Для надёжной проверки Universal Link используйте iPhone с опубликованным AASA-файлом.

Не добавляйте реальные ключи и токены в коммит. Для серверной части приложения понадобится проверка токенов VK ID на сервере.
